# 🔴 Pokemon Scraper - n8n Workflow

An **n8n automation workflow** that extracts Pokémon data from the [PokéAPI](https://pokeapi.co/) and automatically stores it in Google Sheets, sending an email summary upon completion.

> **📌 This is an n8n project!**  
> [n8n](https://n8n.io/) is a powerful workflow automation tool that allows you to connect different services and automate tasks without writing code. This repository contains an exportable workflow that you can import directly into your n8n instance.

## 📋 Description

This n8n workflow automates the following process:

1. **Read Pokémon IDs** from a Google Sheets document
2. **Filter** only records that don't have complete information
3. **Query the PokéAPI** to fetch detailed data for each Pokémon
4. **Extract relevant information**: ID, name, type, and sprites (images)
5. **Update Google Sheets** with the obtained data
6. **Send an email** with a summary of processed Pokémon


## 📊 Google Sheet Structure

Your spreadsheet must have the following columns:

| Column | Description |
|--------|-------------|
| `ID` | Numeric Pokémon ID (1, 2, 3, etc.) |
| `Name` | Pokémon name (will be auto-filled) |
| `Type` | Primary Pokémon type (will be auto-filled) |
| `Sprite Front` | Front image URL (will be auto-filled) |
| `Sprite Back` | Back image URL (will be auto-filled) |

## ⚙️ Credential Configuration

### Recommended Method: Import in n8n

The easiest way is to **import the workflow directly into n8n** and configure credentials through the graphical interface:

1. Open n8n
2. Go to **Workflows** → **Import from File**
3. Select `Pokemon Scraper.json`
4. Click on each node showing a credential error and configure them

### Manual Method: Edit the JSON

If you prefer to edit the JSON file directly, here are the lines you need to modify:

#### 🔐 Required Credentials

| Parameter | Line(s) | Placeholder | Description |
|-----------|---------|-------------|-------------|
| **Google Sheet ID** | 8, 11, 18, 114, 117, 124 | `YOUR_GOOGLE_SHEET_ID` | Your Google Sheets document ID* |
| **Google Sheets Credential ID** | 32, 213 | `YOUR_CREDENTIAL_ID` | Your Google Sheets OAuth2 credential ID |
| **Google Sheets Email** | 33, 214 | `your-email@example.com` | Email associated with the credential |
| **Gmail Credential ID** | 331 | `YOUR_GMAIL_CREDENTIAL_ID` | Your Gmail OAuth2 credential ID |
| **Gmail Email** | 332 | `your-email@example.com` | Email associated with Gmail credential |
| **Recipient Email** | 315 | `your-email@example.com` | Email where you'll receive the summary |
| **Webhook ID** | 328 | `YOUR_WEBHOOK_ID` | Webhook ID (generated by n8n) |
| **Instance ID** | 478 | `YOUR_INSTANCE_ID` | Your n8n instance ID |

> **\*** The Google Sheet ID can be found in the document URL:  
> `https://docs.google.com/spreadsheets/d/`**`THIS_IS_THE_ID`**`/edit`

## 🚀 How to Use

1. **Prepare your Google Sheet** with an `ID` column containing the Pokémon IDs you want to query (1-1025)

2. **Import the workflow** into n8n

3. **Configure the credentials**:
   - Google Sheets OAuth2
   - Gmail OAuth2

4. **Execute the workflow** by clicking "Execute Workflow"

5. **Check your email** for the processed Pokémon summary
